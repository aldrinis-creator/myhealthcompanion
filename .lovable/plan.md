

# Sync with GitHub & Rebuild

Lovable automatically syncs bidirectionally with your connected GitHub repository. Any changes pushed to the main branch on GitHub are pulled into Lovable, and vice versa.

**What you need to do:**

1. **Check GitHub connection**: Go to **Settings → GitHub** in the Lovable editor to confirm your repository is connected and synced to the `main` branch.

2. **Rebuild production bundle**: Click the **Publish** button (top-right) → **Update** to trigger a fresh production deployment at `myhealthcompanion.lovable.app`.

If there are specific commits on GitHub that aren't reflected here, the sync may need a moment to catch up — check Settings → GitHub for sync status.

No code changes are needed from my side for this request. This is a settings/deployment action you perform through the Lovable UI.
